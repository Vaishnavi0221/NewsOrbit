# NewsOrbit 

A modern and responsive news website built using HTML, CSS, and JavaScript. NewsOrbit delivers real-time news updates with a clean interface, category-based filtering, and interactive features.

## Features

- Real-time news updates using News API
- Search news by keywords
- Category filtering
- Trending headlines section
- Responsive design for all devices
- Dark/Light mode toggle
- Smooth animations and hover effects
- Modern card-based UI
- News source and publish date display
- Dynamic content loading

## Categories Included

- Technology
- Business
- Sports
- Entertainment
- Health
- Science

## Technologies Used

- HTML5
- CSS3
- JavaScript
- News API


## How to Run

1. Download or clone the repository
2. Add your News API key in `script.js`
3. Open `index.html` in your browser
